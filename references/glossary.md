# 术语表

## 系统与文献

| 术语 | 释义 |
|---|---|
| 铁板神数 / 铁版神数 | 本 skill 的对象。托名北宋邵雍，实际成型于清代中叶。又称铁版神算、铁板算命、太极数，俗称铁算盘 |
| 「铁版」 | 两说：① 铁一般版本（结果如铁之确凿）；② 铁卜子版本 |
| 铁卜子 / 铁道人 | 清代中叶道士，整理校订条文者，「铁版」之名的来源之一 |
| 皇极分经数 | 明代宫廷御用神数，条文与铁板神数高度相似，被视为岭南派 12000 条版本之始祖 |
| 神机妙算铁版数 | 清道光年间刻印本，现存主流版本的来源；据称著录于《续修四库全书》子部 |
| 邵子神数 / 皇极经世神数 | 铁板神数的别称体系 |
| 算盘数 | 中州等地流传的袖珍式铁板神数 |
| 南派 / 北派 | 南派用日干支、传女、条文 12000 条、流传至中国香港；北派用月干支、传子、近代几近失传 |
| 乾系 / 坤系 | 条文按男女分系 |

## 推算要素

| 术语 | 释义 |
|---|---|
| 天数 | 由**生辰**年月日时求得的数 |
| 人数 | 由**演算时**刻年月日时求得的数。注意：此步使结果与算命当下时间绑定 |
| 地数 | 由所求出的六亲数演得的数 |
| 太玄数 | 干支配数口诀：甲己子午九，乙庚丑未八，丙辛寅申七，丁壬卯酉六，戊癸辰戌五，巳亥单四数 |
| 五音 | 宫商角徵羽，配 土金木火水；由**年干**取 |
| 气数 | 由五音化气所得的字（如「云」）查表得到的数（例：1050） |
| 卦数 | 由干集钥匙表查得的卦对应的数（例：晋卦 900） |
| 先天八卦数 | 乾一、兑二、离三、震四、巽五、坎六、艮七、坤八 |
| 后天八卦数 | 坎一、坤二、震三、巽四、中五、乾六、兑七、艮八、离九 |
| 基本卦 / 基本数序 | 八卦滚的起点。基本数序查《八卦基本配数》表（本仓库未获该表） |
| 八卦滚 | 由基本卦经取爻、变爻、錯卦、对调等步骤推出八卦，每卦出 6 条，共 48 条条文号的算法 |
| 錯卦 | 六爻全变。**本仓库复算确认：八卦滚的第 3、4 卦取法为錯卦，资料误称「互卦」** |
| 互卦 | 取二三四爻为内卦、三四五爻为外卦。**标准互卦取法与资料所列不符，未采用** |
| 条文号 | 查条文库的编号，如 1950、1251 |
| 条文 | 条文库里的一则断语，每条几个到十几个字 |

## 考刻相关

| 术语 | 释义 |
|---|---|
| 考时定刻 / 考刻 | 把一时辰细分为 8 刻，再定到具体刻分的过程。**体系自述其实质为「以果推因」——用六亲事实反推参数** |
| 刻 / 分 | 一时辰 = 8 刻，每刻 = 15 分；每刻再分 15 分。但体系明言此「刻分」用**卦气**而非物理时间 |
| 96 局 | 8 刻 × 12 时辰。也是刻分参数空间的规模 |
| 卦气 | 体系对刻分性质的说明：它不是时钟上的刻度 |
| 五音考刻表 / 考刻十表 / 五音化气表 / 五十气数表 / 干集钥匙表 | 六亲段落所依赖的五张表。**本仓库均未获得** |

## 本仓库使用的分析术语

| 术语 | 释义 |
|---|---|
| 同余式 | `生肖地支序 ≡ 3 + (条文号 − 1151) ÷ 10 (mod 12)`。本仓库复算所得，条文号→生肖的固定映射 |
| 周期 120 | 12 生肖 × 10 编号步长。凡两条条文号之差为 120 的倍数，生肖必然相同 |
| 网格内 / 网格外 | 条文号是否满足 条文号 ≡ 1151 (mod 10)。「父」通常在网格外 |
| 冗余对 | 因差值为 120 的倍数而被编号表强制生肖相同的两条断语。它们不构成独立信息 |
| 等效独立命中数 | 网格内条目中出现过的**不同生肖个数**。衡量一组断语真实承载的信息量 |
| 确定度标注 | `[复现]`（脚本可算且经例题验证）／`[有据]`（资料记载）／`[存疑]`（单一转述）／`[未解]`（口径缺失） |
| `UNRESOLVED` | 本仓库对口径缺失的显式标记。出现即表示不猜、不补 |
