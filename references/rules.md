# 判断规则与判读纪律

## 一、六亲 ↔ 十神对应

| 六亲 | 传统十神 | 铁板神数的输出粒度 |
|---|---|---|
| 父 | 偏财 | 生肖、存殁、寿数 |
| 母 | 正印 | 生肖、存殁 |
| 兄弟 | 比肩／劫财 | **人数**、排行、生肖 |
| 配偶 | 男命正财／女命正官、七杀 | 生肖、**姓氏**、"一字记之曰 X" |
| 子女 | 男命官杀／女命食神、伤官 | **人数**、性别、生肖 |

脚本入口：`tieban.LIUQIN_SHISHEN`。

**粒度差异是本体系最醒目的一点**：八字论六亲是定性的（亲疏、助力），铁板神数给的是**可直接判真伪的离散断言**（生肖 12 选 1）。这既是它"显得神"的原因，也是它唯一的可证伪入口。**而恰恰是这个入口被考刻封住了**（见 `audit.md`）。

## 二、条文的内容分类（体系自述，共十项）

父母出身 · 兄弟姐妹 · 婚姻夫妻 · 子女 · 性格 · 事业财运 · 流年运程 · 师友 · 健康 · 其他

条文分**乾系与坤系**，用于预测具体人生事件；坊间通行版本约 12000 条。

## 三、刻分的口径（三条必须同时记住）

1. **一时辰 = 8 刻**，每刻 15 分；每刻再分 15 分。形式上精确到"分钟"。
2. 但体系自己说：刻分**用的是「卦气」而非物理时间**（「你即使把出生时辰精确到秒，也还可能是错的」）。
3. 由此产生两处后果：
   - **`[复现]` 96 局**：8 刻 × 12 时辰 = 96 局（《大纲歌》：「八刻分命妙无穷，九十六局见天工」）。参数空间可穷举。
   - **`[复现]` 内部矛盾**：「刻分＝卦气、非时间」与「可分辨同卵双胞胎（出生差数分钟即命不同）」**不能同时成立**。二者必居其一。

## 四、体系自认的局限（最值得重视，因为是自己人的证词）

| 局限 | 表述 |
|---|---|
| 推财运、流年不准 | 「铁版神数的最大极限，是推断财运和流年不够准确」 |
| 归因 | 该数是**先天之数**，六亲属先天；财运流年含**后天改造**与趋避，祸福并非一成不变 |
| 六亲与运程用两套卦 | 「先天卦起六亲，后天卦起运程」 |
| 版本缺陷 | 「部分纵卷有缺失，**就算『考时定刻』准确，所推算的条文与正宗卷亦有相关出入**」 |
| 条数口径互斥 | 通行 12000 条；另一派自称共 17.8 万条、遗失 11 万余条、手上仅 6 万条 |
| 内部批评 | 「现在算铁板神数的人**过分注重考六亲，而忘记批章其他部分的重要性，多少倒果为因**」（紫微杨） |

**"推六亲灵、推流年不准"这个自我定位，恰好与「六亲是校准输入」的事实吻合**——能被校准的准，不能被校准的不准。

## 五、本 skill 的判读纪律（硬规则）

1. **不做预测。** 不输出吉凶、婚期、寿数、事业、流年断语。被要求时，改为提供复现与审计结果。
2. **确定度必须标注**：`[复现]` / `[有据]` / `[存疑]` / `[未解]`。
3. **口径缺失即报 `UNRESOLVED`**，不用"通常""一般""大概"填缝。
4. **一切"很准"的传闻降级 `[存疑]`**，除非能提供原始命书 + 事前登记。
5. **同源转载计一份证据。** 多个站点逐字相同时，不得计为"多来源一致"。见 `sources.md`。
6. **"六亲全中"必须先减去同余表强制的重复**，再报数。见 `item-number-table.md` 与 `audit.md`。
7. **不代替用户选定刻分。** 刻分是需要外部确认的参数，代为选定等于把答案当输入。
8. **转述原文判语时标语境。** 本系统的条文含明清语境的道德评价用词；引用时只取可复算的结构信息，不转述为人身评价。
