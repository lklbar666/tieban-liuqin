# 推算步骤

本篇只描述**流程与口径**。凡本机资料不足的部分标 `[未解]`，见 `scripts/tieban.py capability`。

## 一、主流程五步（体系自述口径）

| 步 | 内容 | 可复现性 |
|---|---|---|
| 1 | **求人数**：以**演算时**的年月日时求人数 | `[未解]` 取数表未获；注意此步使结果与算命当下时间绑定 |
| 2 | **求天数**：以**生辰**年月日时求天数 | 部分（太玄数与五音可算，完整数表未获） |
| 3 | **以天数和人数求六亲年命纳音五行与年支** —— 含四子步：① 紫微命盘十二宫取八宫正数；② 河洛先后天命卦 + 流年/流月/流日卦，**配以六亲**；③ 十干变曜配二十八星宿；④ **大定数** | `[未解]`（四子步的取数表均未获） |
| 4 | **求地数**：以六亲数演地数 | `[未解]` |
| 5 | **求铁板数序** → 查条文 | 部分（条文号配对与条号→生肖可算；条文正文不在本仓库） |

**读法**：这套流程里，本仓库能真正跑通的是第 2 步的**部分**（干支取数、五音、八卦滚）与第 5 步的**配对规则**。其余标注为 `[未解]` 是资料缺口，不是可以含糊带过的地方。

## 二、六亲专段：以「父」为锚

公开例题给出的六亲段落可完整复述（例题：乾造 1988-08-19 辰时，戊辰 辛酉 丁亥 甲辰）：

| 步 | 操作 | 本例数值 |
|---|---|---|
| 1 | 查**五音考刻表**：父以**年柱天干**为用。年干戊属土 → 入**宫音** | 宫 |
| 2 | 由**考刻十表**考得**六刻** | 刻 = 6 |
| 3 | 查**五音化气表** → 得字「云」 | 云 |
| 4 | 查**五十气数表**：「云」的气数 | 1050 |
| 5 | 查**干集钥匙表**，纳偏财肖卦为「晋」，卦数 | 900 |
| 6 | 气数 + 卦数 = **父条文号** | 1050 + 900 = **1950** |
| 7 | 由父基数**加减秘数**派生其余五亲 | 母 1151 / 兄弟 1251 / 妻 1651 / 子 1751 / 女 1851 |

两组例题的六亲条文号：

| 亲位 | 例1 | 例2 |
|---|---|---|
| 父 | 1950（蛇） | 1920（虎） |
| 母 | 1151（兔） | 1171（蛇） |
| 兄弟 | 1251（牛） | 1251（牛） |
| 妻 | 1651（蛇） | 1611（牛） |
| 子 | 1751（兔） | 长子 1741（虎）／次子 1751（兔） |
| 女 | 1851（牛） | — |

**可复现部分**：五音（年干→五音，见下）。**`[未解]`**：五音考刻表、考刻十表、五音化气表、五十气数表、干集钥匙表，以及"加减秘数"的取值规则 —— 这四张表与秘数规则本机均未获得，故**父条文号的完整链路无法复原**。

**关键结构观察**：第 2 步「考刻」是这一段里**唯一带自由度的旋钮**，其余全是查表与加减。

## 四、条文生成：八卦滚（已完整复现）

以「基本卦 + 基本数序」为起点：

1. **第一卦**：取基本卦的**二三四爻**为内卦、**三四五爻**为外卦。
2. **加数**：以出生年干支按太玄数取数（三条权重规则见上），加入基本数序 → 得「和」。
3. **第二卦**：和 **÷ 9 取余**定变爻 —— 余 1→初，2→二，3→三，4→四，5→五，6→上，7→初与四，8→二与五，0→三与上。
4. **第三、第四卦**：分别为第一、第二卦的**錯卦（六爻全变）**。
   > **口径更正**：资料把这两卦称作「互卦」。按其六爻结构复算，**取法实为錯卦**（`8/8` 卦名吻合）；标准互卦取法（二三四／三四五）与资料所列不符。本工具从复算结果。
5. **第五至第八卦**：对第一至第四卦按和 **÷ 6 取余**定变爻（余 1→初 … 5→五，0→上），再将**上下卦对调**。
6. **数序**：每卦取三个数序（先天数序、后天数序、及第三个）；从三个数序中取**全部有序对**，按 `前×100 + 后` 得 **6 条**。八卦 × 6 = **48 条条文号**。

```bash
python scripts/tieban.py bagua-gun --basic 乾,坤 --verify-published
```

`[未解]`：**《八卦基本配数》表**（只能由例题得「天地否 = 4410」一例）与**第三个数的取法**（资料逐例给出数值但不给规则）。故本工具要求 `--seq` 由外部输入，且只在显式提供第三数序时才产出条文号，否则报 `UNRESOLVED`。

## 五、最小可用路径

若只想得到一个可核验的结果，走这条：

```bash

python scripts/tieban.py bagua-gun --basic 乾,坤 --verify-published   # 验证算法本体

python scripts/tieban.py audit --entry "父=…,母=…"          # 审计一组断语
```
